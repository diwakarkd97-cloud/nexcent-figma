Nexcent Landing Page

A responsive marketing landing page built with React and custom CSS, based on the Figma Community design "Minimal Landing Page Design | Website Home Page Design | Agency Website UI Design".

The page is split into small reusable components, and all text and image paths live in one data file so the content is easy to change.

Tech Stack
React 18
Vite 5 (dev server and build)
Plain CSS with design tokens (CSS variables), no UI libraries
Inter font (Google Fonts)
Page Sections

From top to bottom:

Header (logo, navigation, Register Now button, mobile menu)
Hero (headline, button, illustration, carousel dots)
Clients (logo row)
Features (three cards)
Spotlight row 1 (illustration + text)
Achievements (four stats)
Spotlight row 2 (illustration + text)
Testimonial (photo, quote, customer logos)
Blog (three post cards)
Call to action
Footer (links, social icons, newsletter field)
