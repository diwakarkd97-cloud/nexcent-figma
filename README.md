# Nexcent Landing Page (React + custom CSS)

Built from the Figma file "Minimal Landing Page Design" (Landing Page frame 211:1738).

    npm install
    npm run dev

1. Export the images listed in `public/assets/README.md` from Figma into `public/assets/`.
2. Colors, type scale, shadows and spacing live in `src/styles/tokens.css`.
3. All copy and asset paths live in `src/data/content.js`.

Structure: `components/ui` (Button, Container, SectionHeading, CarouselDots, Icons),
`components/cards` (FeatureCard, StatItem, LogoTile, BlogCard), `components/sections` (page sections).
